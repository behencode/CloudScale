# CampusConnect video demo guide

This outline produces a clear 5-7 minute walkthrough when you perform the interactions at a natural pace. Use the local demo account and sample listings for the interaction flow; they are fictional and stored only in `backend/data/campusconnect-demo.db`. The local recording path does not call AWS. You can show the deployed URL briefly at the end to demonstrate the live frontend/API health separately.

## Before recording

1. From the repository root, seed the local sample board:

   ```bash
   backend/.venv/bin/python scripts/seed_demo.py
   ```

2. Start the backend in a terminal:

   ```bash
   cd backend
   APP_MODE=local AUTH_MODE=local DATABASE_BACKEND=sqlite STORAGE_BACKEND=local \
   DESCRIPTION_PROVIDER=local CATEGORY_PROVIDER=local NOTIFICATION_BACKEND=local \
   JWT_SECRET=local-video-demo-only-change-me-32bytes \
   SQLITE_PATH="$PWD/data/campusconnect-demo.db" \
   UPLOAD_DIR="$PWD/data/demo-uploads" \
   .venv/bin/uvicorn app.main:app --reload --port 8000
   ```

3. In a second terminal, start the frontend:

   ```bash
   cd frontend
   npm run dev
   ```

4. Open `http://localhost:5173`. Use a clean browser window at 100% zoom and close notifications or unrelated tabs. Confirm the mode banner says local/SQLite/local providers before recording.
5. Sign-in for this local-only sample account is `demo@example.com` with password `CampusDemo123!`. Do not use these credentials on the public AWS deployment.

## Recording checklist

- Keep the video between 5 and 8 minutes if following the assignment requirement; extend the walkthrough with a second listing or a short code/API explanation as needed.
- Keep the backend terminal free of secrets. The demo config uses a local-only placeholder JWT secret.
- Avoid displaying personal email, AWS account identifiers, access keys, console billing details, or other private information.
- If demonstrating image upload, use a non-personal image and explain that the local recording path writes to the ignored local uploads folder.
- Do not present local seed data as live AWS data, or present a defined scaling policy as a demonstrated scale-out event.
- Save the final recording as a separate video file; no demo video is generated by this guide.
